Alur Presensi Karyawan

01

Validasi Geofence GPS

Ponsel memverifikasi posisi koordinat satelit terhadap radius kantor dan memblokir aplikasi fake GPS / mock provider.

02

Verifikasi Wajah (Google MLKit)

Pengambilan foto selfie depan diproses langsung di memori perangkat secara privat tanpa dikirim ke server pihak ketiga.

03

Pencatatan Istirahat & Pulang

Dukungan break monitoring fleksibel dan clock out aman yang otomatis menghitung total durasi shift kerja harian.

04

Antrean Offline & Ekspor PDF

Data presensi tersimpan di SQLite lokal saat offline dan disinkronkan otomatis saat ada koneksi. Ekspor berkas rekapitulasi PDF bulanan langsung dari aplikasi.

Panduan Instalasi APK Manual

  1. 1

    Unduh berkas app-release.apk melalui tombol unduh di bagian atas.

  2. 2

    Buka berkas unduhan dari aplikasi Pengelola File atau bilah notifikasi ponsel.

  3. 3

    Jika muncul peringatan keamanan, buka Pengaturan dan aktifkan "Izinkan dari sumber ini".

  4. 4

    Tekan Install dan berikan izin Lokasi serta Kamera saat pertama kali aplikasi dibuka.
