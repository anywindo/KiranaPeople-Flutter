Fitur Utama & Keunggulan

Dirancang untuk performa tinggi, keamanan enterprise, dan kenyamanan karyawan.

📍

Verifikasi Radius & Anti-Mock GPS

Memastikan kehadiran dicatat tepat di zona kantor/proyek yang ditentukan dengan proteksi spoofing lokasi palsu.

👤

AI Face Detection & Biometrik

Deteksi wajah on-device berkecepatan tinggi dengan Google MLKit untuk memvalidasi identitas saat jam masuk dan pulang.

⏱️

Mode Kerja & Istirahat Dinamis

Fleksibilitas pencatatan jam kerja dan waktu istirahat secara real-time tanpa restriksi alur yang membatasi.

📑

Ekspor Rekap PDF Instan

Unduh laporan bulanan kehadiran rapi berformat PDF lengkap dengan statistik jam kerja, keterlambatan, dan lembur.

📡

Offline-Ready & Sinkronisasi

Tetap mencatat presensi saat koneksi internet offline, dan otomatis tersinkronisasi saat perangkat terhubung kembali.

🛡️

Enkripsi & Token Security (SEC-15)

Penyimpanan kredensial aman di keystore lokal dengan proteksi token leakage ke host luar dan audit logging otomatis.

Panduan Pemasangan APK

Ikuti 4 langkah mudah untuk menginstal aplikasi Kirana People di perangkat Android Anda.

1
Unduh File APK

Klik tombol Download APK di atas atau scan QR code langsung melalui kamera HP Anda.

2
Buka Notifikasi Unduhan

Tarik panel notifikasi atau buka folder Download di pengelola berkas, lalu ketuk file APK.

3
Izinkan Sumber Tak Dikenal

Jika muncul dialog keamanan, klik Pengaturan dan aktifkan "Izinkan dari sumber ini".

4
Pasang & Beri Izin

Klik Install / Pasang. Setelah selesai, buka aplikasi lalu izinkan akses Kamera dan Lokasi.
