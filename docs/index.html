Aplikasi Presensi Kirana People

Sistem pencatatan kehadiran operasional karyawan untuk perangkat Android. Memverifikasi kehadiran di radius kantor melalui koordinat GPS geofence dan validasi foto wajah langsung di perangkat via Google MLKit.

Alur Operasional Presensi

Proses pencatatan aktivitas kerja harian yang dijalankan oleh karyawan melalui aplikasi:

01.

Presensi Masuk (Clock In)

Aplikasi memeriksa koordinat satelit GPS terhadap batas radius kantor yang telah dikonfigurasi. Karyawan mengambil foto selfie kamera depan untuk diverifikasi oleh algoritma deteksi wajah sebelum data dikirim ke backend.

02.

Pencatatan Istirahat (Break Management)

Karyawan dapat mengaktifkan mode Istirahat untuk mencatat awal dan akhir jeda kerja harian. Sistem menghitung durasi istirahat tanpa mengunci alur presensi pulang jika jam kerja telah selesai.

03.

Presensi Pulang (Clock Out)

Pencatatan jam kepulangan dengan validasi lokasi akhir dan foto verifikasi. Total jam kerja shift dihitung otomatis dan dicatat dalam rekapitulasi harian.

04.

Riwayat & Rekapitulasi PDF

Karyawan dapat memeriksa log presensi historis berdasarkan bulan, melihat status ketepatan waktu, dan mengekspor surat rekapitulasi kehadiran bulanan resmi berformat dokumen PDF multi-halaman.

Spesifikasi Teknis & Keamanan

Komponen arsitektur teknis dan protokol keamanan yang diimplementasikan:

Geofencing & Deteksi Anti-Mock GPS

Menghitung jarak titik koordinat ponsel terhadap koordinat kantor menggunakan formula Haversine/Vincenty via plugin geolocator. Memeriksa tanda penyedia lokasi palsu (mock provider) untuk menggagalkan upaya manipulasi lokasi.

Biometrik Wajah On-Device (Google MLKit)

Pemrosesan citra wajah dilakukan secara lokal di perangkat menggunakan model google_mlkit_face_detection untuk memvalidasi keberadaan wajah tunggal tanpa mengirim data mentah foto ke pihak ketiga.

Arsitektur Offline-First (SQLite Queue)

Saat koneksi jaringan terputus atau tidak stabil, transaksi presensi disimpan terenkripsi di database SQLite internal. Begitu jaringan pulih, antrean transaksi disinkronkan secara otomatis ke server utama.

Isolasi Token & Keamanan Host (SEC-15)

Token otentikasi disimpan di hardware Android Keystore melalui flutter_secure_storage. Interceptor jaringan secara ketat memvalidasi host tujuan (ApiConfig.isTrustedHost) agar token Bearer tidak bocor ke domain eksternal.

Deteksi Integritas Perangkat

Memeriksa tanda-tanda rooting pada sistem Android dan modifikasi bootloader yang berpotensi membahayakan integritas data presensi dan enkripsi lokal.

Generasi Dokumen PDF Mandiri

Penyusunan berkas laporan kehadiran bulanan menggunakan pustaka pdf dan printing secara langsung di memori perangkat tanpa membutuhkan dependensi server pembuat PDF terpisah.

Panduan Pemasangan Berkas APK

Tata cara pemasangan aplikasi secara manual pada sistem operasi Android:

  1. 1
    Unduh berkas instalasi

    Klik tombol Unduh APK Universal di bagian atas laman ini. Tunggu hingga peramban selesai mengunduh berkas app-release.apk.

  2. 2
    Buka berkas dari pengelola file

    Tarik tirai notifikasi Android atau buka aplikasi Pengelola Berkas (Files/Downloads), lalu pilih berkas yang baru saja diunduh.

  3. 3
    Berikan izin sumber tidak dikenal

    Apabila sistem Android menampilkan peringatan keamanan sumber luar, pilih tombol Pengaturan lalu aktifkan izin "Izinkan dari sumber ini" (Install Unknown Apps).

  4. 4
    Selesaikan instalasi dan konfigurasi izin

    Tekan tombol Pasang (Install). Setelah pemasangan selesai, buka Kirana People dan setujui permintaan izin akses Lokasi dan Kamera yang dibutuhkan oleh modul presensi.

Pemecahan Masalah & Pertanyaan Umum

Panduan penyelesaian kendala teknis yang kerap ditemui saat penggunaan:

Pesan: "Failed host lookup" atau kendala koneksi server
Kendala ini umumnya terjadi akibat gangguan koneksi data seluler atau kegagalan DNS pada perangkat. Pastikan ponsel terhubung ke jaringan internet yang stabil. Jika menggunakan perangkat pengujian, pastikan alamat backend pada kartu Dev API Endpoint telah dikembalikan ke alamat default.
Pesan: "Lokasi berada di luar radius kerja"
Pastikan layanan GPS/Lokasi perangkat berada dalam mode Akurasi Tinggi (High Accuracy). Jika Anda berada di dalam gedung berdinding tebal, tunggu beberapa detik di dekat jendela atau ruang terbuka agar sinyal satelit GPS terkunci secara akurat.
Kamera tidak dapat mendeteksi wajah
Pastikan wajah menghadap lurus ke arah lensa kamera depan dengan pencahayaan ruangan yang cukup. Hindari penggunaan kacamata hitam pekat atau masker penutup wajah saat proses pengambilan foto presensi.
Apakah data presensi tetap tersimpan jika ponsel kehabisan kuota?
Ya. Aplikasi dilengkapi sistem antrean offline lokal. Catatan kehadiran beserta koordinat dan foto disimpan secara aman di memori lokal ponsel dan akan otomatis disinkronkan ke server saat perangkat kembali terhubung ke jaringan internet.
