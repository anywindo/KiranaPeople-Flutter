Fitur Aplikasi

Validasi Lokasi GPS

Memeriksa koordinat perangkat terhadap radius kantor yang ditentukan dan memblokir penggunaan aplikasi fake GPS.

Deteksi Wajah

Memvalidasi keberadaan wajah pengguna melalui kamera saat mengirim presensi masuk dan pulang.

Pencatatan Shift & Istirahat

Mencatat jam masuk kerja, mulai istirahat, selesai istirahat, dan jam pulang secara berurutan atau langsung.

Ekspor Rekap PDF

Membuat file laporan rekapitulasi kehadiran bulanan dalam format dokumen PDF langsung dari perangkat.

Penyimpanan Offline

Menyimpan data presensi secara lokal saat tidak ada internet dan mengirimkannya ke server saat kembali online.

Penyimpanan Kredensial Aman

Menyimpan token sesi di storage terenkripsi perangkat dan membatasi pengiriman token hanya ke server aplikasi.

Panduan Pemasangan APK

Ikuti 4 langkah mudah untuk menginstal aplikasi Kirana People di perangkat Android Anda.

1
Unduh File APK

Klik tombol Download APK di atas atau scan QR code langsung melalui kamera HP Anda.

2
Buka Notifikasi Unduhan

Tarik panel notifikasi atau buka folder Download di pengelola berkas, lalu ketuk file APK.

3
Izinkan Sumber Tak Dikenal

Jika muncul dialog keamanan, klik Pengaturan dan aktifkan "Izinkan dari sumber ini".

4
Pasang & Beri Izin

Klik Install / Pasang. Setelah selesai, buka aplikasi lalu izinkan akses Kamera dan Lokasi.
